## 1. 产品目标

在 macOS 刘海区域常驻一个轻量的 Codex 用量伴侣，让用户在当前窗口未激活时也能读到 Codex 的 5 小时额度和周额度。折叠态只表达“额度进度”，不展开成遮挡其他窗口的浮层；点击刘海后才进入会话与统计详情。

第一版设计交付物是可交互 HTML 原型，不承诺直接具备原生 macOS 窗口权限或真实数据轮询。原型必须把真实数据接入边界、状态缺省和视觉状态表达清楚，后续可以据此实现 Swift/SwiftUI 或 Electron 容器。

## 2. 已确认的视觉方向

### 2.1 核心形态

- 不是刘海下方的悬浮卡片，也不是左右两个独立小翼。
- 主体是一整块横向拉长的黑色刘海，顶部贴齐屏幕边缘，底部两侧圆润收口。
- 主体高度保持接近原生刘海，横向利用刘海左右的溢出空间。
- 其他窗口内容在刘海下方保持可见，不被额外面板遮挡。

### 2.2 折叠态进度语言

- 折叠态不显示百分比、标题、图表或多余文字。
- 在黑色主体的内沿放一条细、连续、带轻微波浪起伏的描边。
- 描边左侧使用暖珊瑚到橙色，表达 5 小时额度；右侧使用 Mint，表达周额度。
- 中间过渡保持柔和，不使用高亮霓虹或粗线条。
- 进度采用线段长度、亮度和波面位置三种信号组合：使用量越高，当前区段越长、越亮；0% 时只保留极细暗线，100% 时接近完整包围底部内沿。
- 折叠态只保留一个很小的状态点，用于区分“同步中 / 正常 / 过期 / 异常”；不可在刘海内塞入第二层 UI。

### 2.3 展开态

点击黑色刘海后，刘海向下平滑展开为同一窗口，而不是新建一个悬浮卡片。

展开态分为三层：

1. 顶部：5 小时额度、周额度的清晰百分比、重置倒计时和同步时间。
2. 中部：当前会话状态、当前模型、最近一次活动、Token 使用明细。
3. 底部：AIUsage 与 Local usage 两个来源分栏展示，明确标注“本地统计”和“上报统计”，不做合计替代。

## 3. 数据来源与边界

### 3.1 Codex 实时额度

适配器目标：复用本机 aiusage 的额度查询结果。

- 入口：aiusage 本地服务的 `/api/quotas`。
- Codex 窗口：`rate_limit.primary_window` 视为 5 小时额度，`secondary_window` 视为周额度。
- 进度字段：`used_percent`。
- 重置字段：`reset_at` 转成本地时间并显示倒计时。
- 若接口超时或认证失效，保留最近一次成功值，同时把状态点置为“数据可能过期”；无缓存时显示灰色暗线。

### 3.2 AIUsage 本地统计

适配器目标：复用本机 aiusage 的详细统计与会话记录。

- 汇总：`/api/summary?range=day&tool=codex`。
- 日趋势：`/api/tokens?range=week&tool=codex`。
- 会话列表：`/api/sessions?range=day&tool=codex&page=1&pageSize=...`。
- 展示字段：输入 Token、输出 Token、缓存读取 Token、思考 Token、总 Token、成本、活动天数、会话数、最近会话。
- AIUsage 数据只代表本地解析记录，标签统一为“AIUsage · 本地记录”。

### 3.3 Local usage 统计

适配器目标：读取本机 Local usage 采集器生成的独立日汇总。

- 日汇总：由 Settings 配置的本地 CSV。
- 运行状态：可选本地状态文件。
- 关键字段：`date`、`source`、`turns`、`input_tokens`、`cached_input_tokens`、`output_tokens`、`reasoning_output_tokens`、`total_tokens`、`last_success_at`、`upload_code`、`upload_message`。
- UI 标签统一为“Local usage · 上报统计”。
- Local usage 不参与实时额度百分比计算，也不与 AIUsage 数字做相加；它只作为独立统计来源和上传健康度展示。

## 4. 交互状态

### 4.1 折叠态状态机

- `idle`：黑色放大刘海 + 两色波浪描边 + 正常状态点。
- `working`：波浪沿内沿缓慢流动，状态点轻微呼吸；不改变主体高度。
- `stale`：描边降低饱和度，状态点变为暖黄；详情显示最近同步时间。
- `error`：描边保留最近值但降低亮度，状态点变为珊瑚红；点击后显示错误来源和重试入口。

### 4.2 展开/收起

- 点击刘海区域：展开/收起。
- 点击外部：收起，不改变数据。
- 展开动画只改变窗口高度和内容透明度，波浪描边保持连续，避免“断线”感。
- `Esc`：收起。

## 5. 原型范围

本轮高保真原型包含：

- 16:9 桌面背景中的刘海折叠态。
- 5 小时与周额度的动态模拟数据。
- 波浪描边随进度变化的动画。
- 点击展开后的会话/Token/AIUsage/Local usage 分栏。
- 正常、同步中、过期、错误四种状态切换。
- 适配桌面宽度变化，保持刘海主体不覆盖主要窗口内容。

本轮不包含：

- 原生 macOS `NSPanel` / `NSWindow` 实现。
- 真实 OAuth、Keychain、Codex 认证管理。
- 修改或触发 aiusage、Local usage 的上传行为。
- 自动安装 LaunchAgent 或后台常驻服务。

## 6. 验收标准

- 折叠态视觉上是一整块放大版刘海，而不是浮动卡片或两侧独立组件。
- 折叠态除状态点外不出现多余文字和统计卡片。
- 进度通过两侧颜色区段和底部波浪描边表达，5 小时与周额度能被区分。
- 展开态能同时看到 Codex 实时额度、当前会话、AIUsage、Local usage，且来源标签清楚。
- AIUsage 和 Local usage 不合并成一个“总 Token”。
- 数据缺失、认证失效、服务超时都有可见的降级状态。
- Playwright 点击测试覆盖：展开/收起、状态切换、来源分栏切换；控制台无错误。
